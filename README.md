# KernSprache

PWA personale per imparare l'inglese con un tutor IA (correzioni in italiano, dialoghi, ripasso con spaced repetition, notifiche push).

- `apps/web` — PWA React + TypeScript + Vite
- `supabase` — configurazione locale, migration (con RLS), seed e test

Avvio rapido e comandi: vedi la sezione **Comandi** in [CLAUDE.md](./CLAUDE.md).
